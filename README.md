# auto-affiliate-blog

Fully automated affiliate marketing blog via AI-generated content

This repository automatically publishes AI-generated affiliate marketing content to GitHub Pages.

## How It Works

1. **Research**: AI searches for trending topics in profitable niches
2. **Generate**: Creates SEO-optimized blog posts using LLMs
3. **Monetize**: Automatically inserts relevant affiliate links
4. **Publish**: Commits to GitHub → GitHub Actions → GitHub Pages
5. **Earn**: Visitors click affiliate links → commissions
